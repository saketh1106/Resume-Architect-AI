

\# Resume Architect AI



An AI-powered resume-building project designed to help users transform their information into structured resume content.



\## Overview



Resume Architect AI combines a web-based frontend with a backend API to support the resume creation workflow.



\## Tech Stack



\- Frontend: React, TypeScript, Vite

\- Backend: Node.js, Express.js

\- AI Integration: OpenAI API (configured through environment variables)



\## Project Structure



```text

Resume-Architect-AI/

├── client/          # Frontend application

├── server/          # Backend API

├── .gitignore

└── README.md

```



\## Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/saketh1106/Resume-Architect-AI.git

cd Resume-Architect-AI

```



\### 2. Start the backend



```bash

cd server

npm install

```



Create a `.env` file in the `server` directory and configure the required environment variables.



Start the backend using the script defined in `server/package.json`.



\### 3. Start the frontend



Open a second terminal:



```bash

cd client

npm install

npm run dev

```



Open the local URL displayed by Vite in your browser.



\## Security



\- Never commit API keys or secrets.

\- Keep environment variables in `.env` files.

\- Do not upload `node\_modules` or private user uploads.
